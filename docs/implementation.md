# 구현과 실험 기록

명령은 프로젝트 루트에서 실행합니다.

## 동작

- 코드는 충돌, 이동 가능성, 줄 제거와 보드 지표를 계산합니다. 현재 블록 높이에서 이동·회전한 뒤 낙하할 수 있는 모든 후보를 Jev에 보냅니다. 낙하 중 목표의 도달 가능성을 다시 확인합니다.
- Jev는 `POST https://api.typesafe.ai/v1/systemone`의 `choice` 질문 하나로 실제 배치할 후보를 선택합니다. 기본 모델은 `jev-latest`입니다. 서버는 모델의 선택과 확률 분포를 검증합니다.
- 화면에 표시하는 높이·빈틈·줄 제거 수는 코드가 계산한 결과입니다. Jev가 말한 이유나 사고 과정으로 표시하지 않습니다. 확신도와 후보 확률은 승률을 뜻하지 않습니다.
- 실제 모드는 새 블록 또는 일시정지 후 재개할 때 API를 호출합니다. 기본 한도는 무제한이며 25/50/100수로 제한할 수도 있습니다. 유한 한도에서는 시도한 API 요청도 한도에 포함됩니다. 실패/취소된 요청은 사용량을 알 수 없어 화면의 토큰 합계에는 포함되지 않을 수 있습니다. 자동 재시도는 하지 않습니다.
- API 키는 서버 환경 변수를 우선 사용하고, 없으면 브라우저의 Authorization 헤더에서 읽습니다. 정적 파일은 허용 목록으로만 제공하고 서버는 `127.0.0.1`에 바인딩합니다.
- 중력은 기본 650ms마다 한 칸, 10줄마다 빨라집니다(기본 최소 100ms). 속도 설정은 중력과 이동 간격에 적용합니다. Jev 응답을 기다리는 동안에도 내려가며, 바닥에 닿은 상태가 500ms 지속되면 고정됩니다. 늦은 응답으로 도달 불가능해진 목표는 실행하지 않으며 실제 중력 착지를 기록합니다. API 실패 시 일시 정지합니다. 정지·탭 이탈은 현재 블록 위치와 중력 타이머를 보존하고, 재개 시 그 위치에서 새 판단을 요청합니다. 새 게임은 보드를 초기화하고 이전 응답을 적용하지 않습니다.

## 게임 규칙

Jev 응답을 기다리는 동안에는 중력이 적용됩니다. 판단 후 도달 가능한 목표로 이동·회전을 마치면 즉시 하드드롭해 고정합니다. 하드드롭은 바닥 고정 대기 시간을 건너뜁니다.

10×20 보드, 7-bag 무작위 블록, 다음 블록 3개 미리보기. 1/2/3/4줄 제거 점수는 100/300/500/800점입니다. 이 버전은 **실시간 중력 방식**입니다. Jev는 목표 착지를 고르고 코드가 낙하 중 이동·회전을 실행합니다. 홀드, SRS 월킥, 복잡한 밀어 넣기 경로 탐색, T-spin 보너스는 없습니다. 생성 위치가 막히면 게임이 종료됩니다. Jev의 게임 실력은 보장하지 않으며, 실제 성능은 API 키 연결 후 평가해야 합니다.

## 조작

기본 화면은 보드, 점수, 다음 블록, 현재 선택, 선택 확률, 응답 시간과 상위 3개 후보를 한 화면에 요약합니다. **판단 상세**를 열면 일시 정지되며 모델 확신도, 열·회전별 확률 합계, 전체 후보 비교표와 최근 5수 기록을 확인할 수 있습니다. 합산 확률은 같은 Choice 응답을 집계한 값이며 별도 모델 판단이 아닙니다.

지연시간은 서버에서 Jev 요청을 시작해 응답을 읽고 검증할 때까지의 왕복 시간입니다(네트워크 포함). 순수 모델 추론 시간이 아닙니다. 현재 요청의 브라우저 대기 시간과 성공 응답의 게임 내 평균·최대도 별도로 표시하며 실패·취소된 요청은 통계에서 제외합니다.

- **시작 / 정지 / 계속**, **새 게임**
- Space: 시작/정지 (버튼·선택 상자에 포커스가 없을 때)
- 게임 한도: 무제한(기본)/25/50/100수. 한도 도달 후 늘리면 이어서 실행 가능

## 비용

누적 예상 비용은 입력 토큰 × $0.042 / 1,000,000으로 계산합니다(출력 무료, Jev 1.13 공식 요금, 2026-09-30 확인). 이 기능 적용 후 같은 탭에서 받은 응답만 집계하며 새 게임과 새로고침에도 유지합니다. 과거 사용량이나 다른 탭·평가 스크립트의 호출은 포함하지 않습니다. 실패·취소·알 수 없는 모델/사용량은 미확인 비용으로 `+ ?`를 붙입니다. 실제 청구액은 TypeSafe 콘솔에서 확인하세요.

## 검증

```sh
node --test
```

외부 패키지 설치나 API 키 없이 실행됩니다. GitHub Actions에서도 Node.js 22·24로 같은 테스트를 실행합니다.

Node 내장 테스트로 회전, 충돌, 4줄 제거, 게임 종료, 블록 분배, 고정 시드 시뮬레이션, Jev 요청·응답 계약, 오류 처리와 HTTP 경계를 검증합니다. API 테스트는 모의 응답을 사용하며 실제 Jev 성능 검증과 구분됩니다.

### 프롬프트 비교

입력은 각 후보를 시뮬레이션한 뒤 막힌 빈칸의 증감, 즉시 제거되는 줄, 천장까지 남은 높이와 다음 블록 생성 가능 여부를 문장으로 설명합니다. 열린 우물과 막힌 빈칸을 구분하고, 표면을 평평하게 만드는 것보다 아래 공간을 막지 않는 것을 선호하도록 요청합니다. 후보 필터링이나 모델 선택을 덮어쓰는 규칙은 없습니다.

`node --env-file-if-exists=.env eval/compare.mjs`는 실제 API를 24회 호출합니다. 기존·변경 프롬프트를 고정된 12개 보드와 `jev-1.13.0`으로 비교한 결과는 `eval/results.json`에 저장됩니다. 저장된 결과는 실시간 중력을 도입하기 전 프롬프트의 1회 비교 기록입니다. 현재 코드로 다시 실행하면 프롬프트가 달라 결과가 달라질 수 있습니다. 당시 결과 보드의 빈칸 합계는 8→3, 즉시 제거 줄 합계는 9→9였습니다. 일부 선택은 빈칸 대신 높이를 늘렸습니다. 이는 보드별 1회 평가이며 장기 생존율이나 일반적인 성능 향상을 입증하지 않습니다. 문장형 입력은 토큰 사용량이 더 큽니다.

## 파일 구성

- `public/`: 화면, 게임 엔진, 효과와 통계 표시
- `server.mjs`: 로컬 HTTP 서버와 API 프록시
- `jev.mjs`: Jev 입력 구성과 응답 검증
- `test/`: API를 호출하지 않는 자동 테스트
- `eval/`: 실제 API를 사용하는 프롬프트 비교와 과거 결과
- `.agents/skills/typesafe-ai/`: 개발 시 사용하는 TypeSafe 스킬과 해당 라이선스

이 앱은 Node.js 서버가 필요하므로 GitHub Pages만으로 실행할 수 없습니다. `.env`는 Git에서 제외되며 `.env.example`만 공유합니다.
